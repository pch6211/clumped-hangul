# 폰트 익스포트 (타입으로 직접 내보내기)

화면의 뭉친 한글 글자를 **실제 폰트 파일(OTF)** 로 내보낸다.

## 현재: 정적 OTF (구현·검증 완료)
- **트리거**: `Ctrl/Cmd + Shift + F` (또는 콘솔 `await exportClumpedFont()`)
- **동작**: 현재 화면의 각 음절(`world.bodies`)을 코드포인트별 글리프로 만들어 OTF 다운로드.
- **검증**: 라이브 "뭉친 한글" → 4글리프 OTF(magic `OTTO`) 생성 확인. node 단위 테스트로
  opentype.parse 라운드트립·글리프 path·메트릭 검증 통과.

### 파이프라인
1. `main.js` `window.__chFontGeometry()` — saveSVG 와 동일 모델로 글자별 기하 추출
   (획=선분+폭, 노드=둥근사각). 흘리기(장식) 제외.
2. `src/font/build-font.js` (순수·테스트가능):
   - 획 → 캡슐(스타디움) 다각형, 노드 → 둥근사각 다각형
   - `polygon-clipping` 합집합 → 닫힌 윤곽 (실패 시 개별 다각형 폴백, nonzero fill)
   - 화면좌표(y↓) → 폰트좌표(y↑, em 스케일, 글자 하단=베이스라인)
   - `opentype.js` Path/Glyph/Font → OTF ArrayBuffer
3. `src/font-export.js` — 기하 읽기 → (지연 import)buildFont → 다운로드. 단축키·토스트.

### 알려진 한계 / 다듬을 점
- 글자별 독립 스케일(각 글자를 em 높이에 맞춤) — 통일된 글로벌 메트릭/베이스라인·디센더는 추후.
- 한글 11,172자 전수 불가 — 화면에 있는 글자만 내보냄. (세트 지정 익스포트는 확장 여지)
- 다중 코드포인트 문자(일부 이모지)·합자는 미지원.
- TTF(쿼드라틱) 출력은 미구현(현재 OTF=큐빅/CFF). 필요 시 opentype.js TTF 경로 추가.

## 다음: 가변 TTF (A→B 애니메이션) — 설계만, 미구현
요청: "애니메이션 A→B 를 설정한 뒤 가변 TTF 로 뽑기."

타당성: **가능하지만 고급.** 가변 폰트는 마스터 간 **윤곽 토폴로지가 동일**해야 보간된다.
이 앱의 A→B 는 물리가 **노드 위치만** 옮기는 것이라 노드·엣지 구조가 보존돼 궁합이 좋다.

핵심 조건 / 접근:
- **합집합을 하면** 윤곽 개수가 상태마다 달라질 수 있다 → 가변엔 부적합.
  대신 **획별 캡슐·노드별 윤곽을 합치지 않고** 각각 고정 점수로 유지하면 토폴로지 안정.
  (겹쳐도 nonzero fill 로 시각상 동일)
- 마스터 A(예: 안정/펼침) · 마스터 B(뭉침) = 같은 점 구조, 좌표만 다름.
- `fvar`/`gvar` 작성은 opentype.js 만으론 빡빡 → **fontTools(Python) varLib** 경로가 현실적
  (이 환경에 python3 3.11 있음). 또는 gvar 직접 작성.
- 커스텀 축 예: `CLMP`(clump) 0–100.

→ 정적이 안정화됐으니, 가변은 토폴로지-안정 기하 추출(합집합 off 모드) + fontTools 파이프라인을
   별도로 붙이는 순서로 진행 권장.
