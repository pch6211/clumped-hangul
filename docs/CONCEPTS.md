# 개념·용어 노트 (쉬운 풀이)

개발/기술 용어가 처음 나올 때마다 **초보·바이브코딩 입장에서 쉽게** 한 줄로 풀어 적는 곳.
(이미 한 번 설명한 건 여기 모여 있으니, 헷갈리면 여기서 찾으면 됨.)

## 깃 / 협업
- **깃(Git)**: 코드의 "타임머신". 언제든 과거 버전으로 되돌리고, 누가 뭘 바꿨는지 추적.
- **브랜치(branch)**: 메인 코드를 안 건드리고 따로 떠서 작업하는 평행우주. 망쳐도 메인은 안전. (지금 `Jisung_01`)
- **커밋(commit)**: 작업 한 묶음을 저장하는 "스냅샷 / 되돌리기 지점".
- **푸시(push)**: 내 커밋들을 깃허브(인터넷 원격 저장소)에 올리는 것.
- **PR(풀 리퀘스트)**: "내 브랜치 작업을 메인에 합쳐도 될까요?" 요청 + 리뷰 절차.
- **회귀(regression)**: 고치다가 멀쩡하던 게 망가지는 것. "비회귀 확인" = 안 망가졌는지 검증.

## 빌드 / 개발 도구
- **번들러(bundler)**: 흩어진 코드 파일들을 브라우저가 잘 먹도록 하나로 묶고 압축하는 도구.
- **Vite(비트)**: 요즘 많이 쓰는 빌드 도구. 개발 중엔 수정 즉시 반영, 배포 땐 최적화 묶음 생성.
- **HMR(핫 모듈 리로드)**: 코드 고치면 새로고침 없이 바뀐 부분만 화면에 즉시 반영.
- **TypeScript(타입스크립트)**: 자바스크립트에 "이 값은 숫자/글자" 같은 라벨을 붙여 실수를 미리 잡아주는 버전.
- **ES 모듈(module) / import·export**: 코드를 파일로 나누고 "이건 가져다 써"라고 주고받는 표준 방식.
- **모듈 스코프(scope)**: 모듈(파일) 안에서 만든 함수·변수는 그 파일 안에서만 보임(전역 오염 방지).
  그래서 파일을 나눌 때 "서로 어떻게 가져다 쓸지" 신경 써야 함.
- **모노리스(monolith)**: 모든 게 한 파일/덩어리에 든 구조. 나눠서 관리 좋게 하는 게 "모듈화".
- **린터(linter) / 포매터(formatter)**: 린터=코드 실수·냄새 잡기, 포매터=들여쓰기·줄바꿈 자동 정리. (Biome가 둘 다)
- **지연 로딩(lazy import) / 코드 스플리팅**: 무거운 코드는 처음에 안 불러오고 "필요할 때" 불러와 초기 로딩을 가볍게.
- **React / Next**: UI를 부품(컴포넌트)처럼 짜는 인기 프레임워크. 단, 이 앱처럼 캔버스에 직접 그리는 앱엔
  잘 안 맞아서 **안 씀**.

## 웹 / 화면
- **DOM**: 웹페이지 요소(버튼·입력창 등)들의 구조 트리. JS가 이걸 조작해 화면을 바꿈.
- **canvas(캔버스)**: 그림판 같은 자유 그리기 영역. 이 앱은 한글을 여기에 직접 그림.
- **IME 조합(한글 입력)**: 한글은 ㄱ+ㅏ→"가"처럼 조합해 입력됨. 그 조합 과정을 다루는 이벤트.
- **이벤트 캡처(capture phase)**: 키·클릭 이벤트가 바깥→안 순으로 먼저 전달되는 단계.
  기존 처리보다 "먼저" 가로채고 싶을 때 씀.

## 배포 / 자동화
- **GitHub Pages**: 깃허브가 무료로 웹사이트를 띄워주는 기능. (clumped-hangul.com이 이걸로 서비스 중)
- **GitHub Actions (CI/CD)**: 코드 올리면 자동으로 빌드·배포 등을 돌려주는 "로봇 일꾼". CI/CD = 자동 통합/배포.
- **Electron(일렉트론)**: 웹앱(HTML/JS)을 그대로 데스크탑 앱으로 감싸는 도구. 크롬을 내장해 어디서나 똑같이 보임.
- **Tauri(타우리)**: Electron 대안(더 가벼움, Rust 언어 필요). 이 프로젝트는 렌더 일관성 때문에 Electron 선택.

## 폰트
- **OTF / TTF**: 폰트(글꼴) 파일 형식. 둘 다 글자 모양 데이터. (OTF는 곡선 표현이 부드러운 편)
- **윤곽선(outline) / 채우기**: 폰트 글자는 "선"이 아니라 "닫힌 외곽선 안을 채운" 모양으로 정의됨.
- **다각형 합집합(polygon union)**: 여러 도형을 하나로 합쳐 바깥 윤곽선만 남기는 계산.
  (이 앱: 획+점을 합쳐 한 글자의 외곽을 만듦)
- **가변 폰트(variable font)**: 한 폰트 안에서 굵기·모양을 슬라이더로 조절할 수 있는 폰트. A→B 사이를 부드럽게 보간.
- **opentype.js**: JS로 폰트 파일을 읽고 만드는 라이브러리(도구 묶음).
- **em / 베이스라인(baseline)**: em=폰트의 기준 사각형 크기, 베이스라인=글자가 앉는 바닥선.

## 디자인 연동
- **Figma(피그마)**: 디자인 툴. 화면 UI를 그리고 수정.
- **Code Connect**: Figma 컴포넌트와 코드 컴포넌트를 연결해 디자인↔코드를 일치시키는 Figma 기능.

## 문서/관리 약어
- **ADR(아키텍처 결정 기록)**: "왜 이렇게 정했는지"를 짧게 남기는 문서. (docs/DECISIONS.md)
- **헤드리스 / 오프스크린**: 화면에 창을 안 띄우고 백그라운드로 렌더/캡처하는 것.
