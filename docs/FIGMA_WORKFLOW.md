## 디자인 토큰 (코드에서 추출 — 재현 시 이 값 사용)
- **배경 기본**: `rgb(93,195,216)` 하늘색 (`bgR/bgG/bgB`, 사용자 조절·랜덤 가능)
- **글자색 기본**: `rgb(0,0,0)` 검정 (`fgR/fgG/fgB`, 배경에 자동 매칭)
- UI 폰트: `sans-serif`, 작은 라벨 ~10px, HUD ~11px (좌하단 정렬). UI 여백 변수 `--ui-gap:16px`.
- 주요 UI 표면색: 반투명 패널/버튼(테두리 `currentColor`, 배경 `transparent`/`--editor-bg`).

## 주요 장면 (재현 대상)
1. **메인 뷰** — 중앙 클럼프 한글 캔버스 + 좌상단 "텍스트" 입력박스 + 좌측 HUD + 우하단(의견/커피/크레딧).
   - HUD 단축키: 자동재생 `A`, 글자리셋 `B`, 설정창 `S`, 문자창 `E`, 임의설정 `R`,
     임의텍스트 `T`, 자간·행간 `Alt+화살표`, 획잇기취소 `Ctrl+Z`, 편집메뉴 `글자 우클릭`, 가이드 `M`.
2. **설정 창 (`S`)** — 슬라이더(점간격·점크기·획크기·자간·행간·골격분할·물리·자석), 색상 선택기, 꾸밈 토글, 파일 IO, 관리자 모드.
3. **편집 창 (`E`)** — 자모 리스트 사이드바 + 노드/획 편집 캔버스 + 모임꼴 모드.

## 양방향 워크플로우
- **코드 → Figma (재현/동기화)**: `figma-generate-design` 스킬 + `use_figma`(MANDATORY: 먼저 `figma-use` 스킬 로드)
  로 위 장면을 프레임/컴포넌트로 생성. 색은 Figma **변수(라이트/다크 또는 배경 프리셋)** 로,
  버튼·슬라이더·패널은 **컴포넌트**로 만들어 재사용·수정 용이하게.
- **Figma → 코드**: 사용자가 Figma에서 수정 → `get_design_context`/`get_screenshot` 으로 읽어 코드 반영.
- **Code Connect**: Figma 컴포넌트 ↔ 코드 컴포넌트(향후 UI 모듈) 매핑(`*.figma.ts`)으로 정합 유지.

## 재현 계획 (다음 협업 세션 권장 순서)
1. **변수/스타일 먼저**: 색상(배경 프리셋·글자색), 타이포(라벨/HUD), 간격(`--ui-gap`)을 Figma 변수로.
2. **컴포넌트**: pill 버튼(의견/커피/패널), 슬라이더 행, 색상 선택기, HUD 행(라벨+키캡).
3. **장면 조립**: 메인 뷰 프레임(1440×900 등) → 설정 창 → 편집 창. 캔버스 본문은
   생성형이라 스크린샷/플레이스홀더 프레임으로 표현.
4. **Code Connect** 매핑은 UI 모듈 분리(P0-4 후속) 진척에 맞춰.
